# قائمة عيادات جدة للاتصال — دفعة أولى

المصدر: بحث Google Maps (خرائط قوقل) عبر Chrome بتاريخ 2026-09-02.
البحث: «عيادات أسنان جدة» + «عيادات جلدية وتجميل جدة».

## معيار الاختيار — "عيادات عندها ضغط"

استخدمت **عدد المراجعات** كمؤشر على حجم المرضى (الضغط على الاستقبال). ركّزت على:

1. **حجم مراجعات عالٍ (500+)** = تدفق مرضى كبير = مكالمات ورسائل ما يلحق عليها موظف واحد.
2. **مجمعات وفروع متعددة** = خط هاتف واحد يخدم كل الفروع.
3. **تقييم متوسط (3.3–4.4) مع حجم كبير** = شكاوى تعامل/انتظار = أقوى زاوية بيع.
4. **بدون موقع إلكتروني** = حضور رقمي ضعيف، كل الحجز يدوي (عيادة درة العالمي، عيادة الليزر).
5. **يصرفون على إعلانات** (جذور الأسنان، مركز الطبابة) = وضع نمو، مستعدين يدفعون لأدوات.
6. **مفتوح 24 ساعة** (عائلتي، سابا) = مكالمات بعد الدوام تضيع بالكامل.

## الملف

`jeddah-clinics.csv` — 15 عيادة، لكل واحدة: الاسم، النوع، التقييم، عدد المراجعات، الهاتف، الموقع التقريبي، ووجود موقع إلكتروني، و**زاوية البيع** (السبب المحدد اللي تفتح فيه المكالمة).

## أفضل 3 للبدء فيهم

| العيادة | ليش أولوية |
|--------|-----------|
| **مجمع عائلتي الطبي** (3.4 / 1,656 / 24 ساعة) | ألم الاستقبال ظاهر في التقييم — أسهل إقناع |
| **عيادات سابا الصفا** (4.6 / 8,924 / 24 ساعة) | أعلى ضغط استقبال في القائمة بفارق كبير |
| **مجمع درة العالمي** (4.6 / 1,791 / بدون موقع) | حجم كبير + حضور رقمي ضعيف = حاجة واضحة |
